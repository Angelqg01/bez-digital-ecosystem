# Edge Node Manager

Panel de control para los administradores y operadores de la red de nodos perimetrales (Edge Nodes) descentralizados DePIN.

## Características
- **Dashboard Global**: Monitoreo de *Network Health*, TPS, uptime, y estado general.
- **Gestión de Nodos**: Despliegue de nuevos nodos validadores utilizando el API Gateway de BeZhas.
- **Recompensas (Rewards)**: Visualización y reclamo de BEZ-Coin ganados por la validación de bloques y análisis de *Gemini Vision*.
- **Autenticación SSO**: Tokenización de la sesión compartida con el *BeZhas Hub*.

## Ejecución Local
```bash
cd edge-node-manager
pnpm install
pnpm dev
```
Puerto de desarrollo: **3012**
URL Local: `http://localhost:3012`
