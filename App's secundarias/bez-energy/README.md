# BeZhas Energy (bez-energy)

Sistema de gestión energética híbrida e IoT para el ecosistema BeZhas.

## Características Principales
- **SCADA Dashboard**: Panel de monitoreo de cuadrícula (Grid) y consumo.
- **Aegis / Seguridad**: Monitoreo de integridad de los nodos validadores.
- **Energy Wallet**: Billetera para la gestión y rentabilización de tokens energéticos (NegaW).
- **Documentación Completa**: Consulta los análisis de rentabilidad y tokenomics en la carpeta `/docs`.

## Ejecución Local
```bash
cd bez-energy
pnpm install
pnpm dev
```
