# BEZ_Scaner - Sub App de Logística para BeZhas Blockchain

## Descripción
Esta sub-app conecta el sector logístico con la blockchain de BeZhas usando contratos inteligentes y webhooks.

## Configuración
1. Copia las credenciales en el archivo `.env`.
2. Instala dependencias con `npm install`.
3. Edita `src/index.js` para agregar lógica de negocio y direcciones reales de contratos.

## Estructura
- `.env`: Credenciales y configuración.
- `src/contracts.js`: ABIs de contratos.
- `src/index.js`: Ejemplo de conexión y lógica principal.

## Dependencias
- ethers.js
- dotenv

## Ejecución
```bash
npm install
npm start
```
