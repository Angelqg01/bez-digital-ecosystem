# BeZhas-Blockchain Developer Portal

Documentación completa para integrar BeZhas en tu plataforma. Elige tu camino:

## 🚀 Inicio rápido

- **[SDK JavaScript/Node](#sdk)** — Librería npm para cualquier plataforma
- **[REST API](#api)** — Endpoints HTTP para pagos, settlement, webhooks
- **[MCP Server](#mcp)** — Integración con n8n, Zapier, Make (AI-first)
- **[Plugin WordPress](#wordpress)** — WooCommerce, instalación automática
- **[ERP Integration](#erp)** — SAP, Oracle, Odoo, Sage
- **[Smart Contract ABI](#abi)** — Interfaces blockchain (BeZhasPayment, Settlement)
- **[Nodos y Validadores](#nodes)** — Ejecutar tu propio nodo RPC
- **[SubApps Manual](#subapps)** — Cómo usar CargoLink, Capital, Hub, Energy, etc.
