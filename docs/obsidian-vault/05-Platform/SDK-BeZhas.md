# SDK BeZhas

> Capa 2 · Prioridad **P1** · [[Cluster-nucleo-blockchain]]

@bezhas/sdk v3 (registry multi-chain, módulos por sector, cubre las 13 SubApps) y @bezhas/connect (embed B2B: Pay + CargoLink + Capability Registry + widget <script>, 30 tests).

**Ubicación:** `sdk/ + App-nativas/packages/connect`

## Para clientes

Hay dos paquetes para desarrolladores. El SDK (@bezhas/sdk) da acceso multi-cadena a los contratos y módulos por sector, y cubre las SubApps del ecosistema. Connect (@bezhas/connect) permite incrustar en la web de una empresa los cobros de Pay y la logística de CargoLink con un widget que se añade con una etiqueta script. Para conectar una IA existe además el servidor MCP.
