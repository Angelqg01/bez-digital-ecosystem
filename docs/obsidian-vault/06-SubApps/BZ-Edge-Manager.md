# BZ Edge Manager

> Capa 2 · Prioridad **P1** · [[Cluster-infra-devops]]

Gestión de edge nodes B2B: registro, salud, recompensas (EdgeNodeRewards).

**Ubicación:** `App-nativas/edge-node-manager/` · edge.bezhas.com

## Para clientes

BZ Edge Manager será el panel para gestionar los Edge Nodes de una empresa: alta, estado de salud y recompensas. Aún no está disponible al público; el alta del Edge Node se hace hoy desde el onboarding de la plataforma.
