   GET  /api/gateway/v1/contracts/:name  → Info de contrato

 ADMIN AUTH ENDPOINTS (api/routes/admin-auth.js):
   GET  /api/admin-auth/nonce          → Generar nonce SIWE (anti-replay)
   POST /api/admin-auth/login          → Login con credenciales (bcrypt server-side)
   POST /api/admin-auth/wallet-login   → Login con firma wallet (SIWE + nonce)
   POST /api/admin-auth/verify         → Verificar sesion admin activa
   POST /api/admin-auth/logout         → Cerrar sesion admin (limpiar cookie)

 ADMIN FRONTEND ROUTES (control-center/frontend):
   /admin/login                        → Pagina login admin (Credentials + Wallet)
   /admin/profile                      → Panel admin (Hybrid Control Center)

 SEGURIDAD DEL LOGIN ADMIN:
   - Credenciales: verificadas SERVER-SIDE con bcrypt (hash $2a 12 rounds)
   - Wallet: firma SIWE verificada server-side con ethers.verifyMessage()
   - Nonce anti-replay: generado por servidor, uso unico, expira 5 min
   - Rate limit: 5 intentos / 15 min por IP (Redis)
   - JWT: almacenado en cookie HttpOnly (no accesible por JS client-side)
   - JWT expira en 2h, emisor validado (bezhas-admin-auth)
   - Audit trail: cada intento de login se registra en ai_logs (IP, UA, resultado)
   - Timing-safe comparison para username (previene timing attacks)
   - Env vars: ADMIN_USERNAME, ADMIN_PASSWORD_HASH, ADMIN_WALLET (nunca en frontend)
