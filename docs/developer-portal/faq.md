# Preguntas Frecuentes (FAQ)

## Problemas Comunes

**¿Dónde obtengo mi API Key?**
Solicítala en el portal o canal oficial de Discord.

**¿Cómo conecto mi wallet a la testnet?**
Sigue la guía de primeros pasos y añade la red BeZhas Testnet en Metamask.

**¿Qué hago si tengo un error 401?**
Verifica que tu API Key esté activa y correctamente configurada en los headers.

**¿Puedo desplegar mis propios contratos?**
Sí, en la testnet puedes desplegar contratos compatibles con EVM. Para mainnet, solicita revisión previa.
