# BeZhas Developer Portal

> Plataforma modular Web3 para automatización, trazabilidad y tokenización multi-sectorial.

## Bienvenido
El portal de desarrolladores de BeZhas es tu punto de partida para construir, integrar y desplegar soluciones sobre la blockchain BeZhas. Aquí encontrarás documentación técnica, SDKs, APIs, contratos inteligentes y herramientas MCP para todos los sectores soportados.

### Sectores soportados
- Logística, Bienes Raíces, Salud, Energía Renovable, Automotriz, Manufactura, Agricultura, Seguros, Educación, Entretenimiento, Legal, Supply Chain, Gobierno, Finanzas, Servicios, Otros.
