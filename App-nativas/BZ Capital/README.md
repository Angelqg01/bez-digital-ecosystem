# BZ Capital

BZ Capital es el brazo financiero y de Inversión (DeFi / RWA) nativo del Ecosistema BeZhas, construido sobre *Next.js App Router*.

## Características
- **Real World Assets (RWA)**: Inversión en activos físicos logísticos, portuarios e inmobiliarios fraccionados.
- **Yield Farming & Liquidez**: Gestión de retornos, pools de capitales corporativos.
- **SSO Server-Side**: Middleware y `SSOProvider` inyectados en la raíz para garantizar acceso directo sin interrupciones desde el Hub.

## Ejecución Local
```bash
cd "BZ Capital"
pnpm install
pnpm dev
```
Puerto de desarrollo: **3014**
URL Local: `http://localhost:3014`
