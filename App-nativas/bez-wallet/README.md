# BeZhas Wallet

BeZhas Wallet es la billetera oficial descentralizada y nativa del ecosistema **BeZhas Web3 Enterprise Grade**.

## Características
- **Autenticación Delegada (SSO)**: Integrada al *BeZhas Hub* para iniciar sesión con un solo clic.
- **Gestión de BEZ-Coin**: Transferencia de tokens, consulta de saldos y transacciones.
- **Transacciones Seguras**: Interacción con la Layer 2 de BeZhas (Chain ID: 2708).

## Ejecución Local
```bash
cd bez-wallet
pnpm install
pnpm dev
```
Puerto de desarrollo: **3010**
URL Local: `http://localhost:3010`
