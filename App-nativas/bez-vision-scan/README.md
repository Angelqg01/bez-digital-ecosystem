# BeZhas Vision Scan

BeZhas Vision Scan es el sistema de validación visual e inteligencia artificial (IA Oracle) para el ecosistema logístico de BeZhas.

## Características
- **Gemini Vision**: Integración directa con los modelos multimodales para análisis de activos, empaquetado e infraestructura física en tiempo real.
- **Carga de Datos Físicos a la Cadena**: Actúa como puente (Oracle) entre contenedores del mundo real y contratos inteligentes (Smart Contracts).
- **Single Sign-On (SSO)**: Redirecciones y persistencia desde el Hub principal.

## Ejecución Local
```bash
cd bez-vision-scan
pnpm install
pnpm dev
```
Puerto de desarrollo: **3013**
URL Local: `http://localhost:3013`
